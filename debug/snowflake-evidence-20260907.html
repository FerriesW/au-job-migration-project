The one number worth remembering

Over the same six questions, BigQuery scanned 622,713 bytes and Athena 4,727,503 — 7.6× more for identical answers. That is storage format, not workload: BigQuery reads only the columns a query names, Athena decompresses and parses whole JSON objects. Snowflake cannot be placed on that axis at all — a 5.7-second build bills roughly 66 seconds of warehouse uptime because AUTO_SUSPEND = 60. You pay for the idle timeout, not the work.
